# Contributing

Open an issue or propose a pull request with a focused change. Include the Excel version, platform, layout language, reproduction steps and expected result. Use fictional descriptions and amounts; do not upload production budgets, personal data or third-party templates.

The checker is implemented entirely in its worksheet document module. Keep the whole-sheet copy workflow working. Test the changed workbook in native desktop Excel and describe unsupported layouts honestly. See docs/DEVELOPMENT.md.
